# Fortnite

Обход блокировок **Fortnite**, **Epic Games Store**, лаунчера и сервисов Epic Games.

При установке автоматически создаётся изолированный профиль для тестирования стратегий Fortnite.

### Что включено

- Матчмейкинг, лаунчер, загрузки и сервисы Epic
- Epic Games Store, CDN, библиотека
- Discord-интеграция (STUN/UDP порты)

### Рекомендации

- Используйте `ipset_mode: any` и `game_mode: tcpudp` (уже настроено автоматически)
- При проблемах с подключением попробуйте альтернативные стратегии (ALT9, ALT9.1, ALT9.1.1)
